바로처리 SEO 업데이트 적용 안내

1. VS Code 터미널에서 현재 작업을 먼저 백업합니다.
   git add .
   git commit -m "backup before SEO update"

2. 이 ZIP 안의 파일과 폴더를 모두
   C:\Users\airhe\Projects\baro-cheori
   안에 복사하고, 같은 이름의 파일은 덮어씁니다.

3. VS Code 터미널에서 아래 명령을 차례대로 실행합니다.
   npm install
   npm run lint
   npm run build
   npm run dev

4. 브라우저에서 http://localhost:3000 을 확인합니다.

5. 이상이 없으면 아래 명령으로 GitHub에 올립니다.
   git add .
   git commit -m "SEO foundation and service pages"
   git push

6. Netlify 배포가 성공한 뒤 SEO_REGISTRATION_GUIDE.md를 따라
   Google Search Console과 Naver Search Advisor를 등록합니다.

문제가 생기면 터미널의 빨간 오류 화면을 캡처해 전달해주세요.
