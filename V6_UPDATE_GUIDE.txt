바로처리 V6 적용 안내
=====================

이번 ZIP은 프로젝트 전체가 아니라 변경된 파일만 들어 있습니다.
기존 D:\Projects\baro-cheori 폴더에 덮어쓰면 됩니다.

1. 받은 ZIP 파일 이름을 확인합니다.
   baro-cheori-content-v6-20260818.zip

2. ZIP 파일을 D:\Projects\baro-cheori 폴더 안으로 옮깁니다.

3. VS Code 터미널에서 아래 명령을 위에서부터 한 줄씩 실행합니다.

cd D:\Projects\baro-cheori
Expand-Archive -LiteralPath ".\baro-cheori-content-v6-20260818.zip" -DestinationPath "." -Force
Remove-Item -LiteralPath ".\baro-cheori-content-v6-20260818.zip"
npm run lint
npm run build

4. build 중 `Generating static pages ... (59/59)`가 보이고 오류 없이 끝나면 아래 명령을 실행합니다.

git add .
git commit -m "add pickup delay and slow internet guides"
git push

5. Netlify는 GitHub main 브랜치의 새 커밋을 자동으로 배포합니다.
   수동 Trigger deploy는 누르지 않아도 됩니다.
