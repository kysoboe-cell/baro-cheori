바로처리 V5 적용 안내
=====================

이번 ZIP은 프로젝트 전체가 아니라 변경된 파일만 들어 있습니다.
기존 D:\Projects\baro-cheori 폴더에 덮어쓰면 됩니다.

1. 받은 ZIP 파일 이름이 아래와 같은지 확인합니다.
   baro-cheori-content-v5-20260818.zip

2. ZIP 파일을 D:\Projects\baro-cheori 폴더 안으로 옮깁니다.

3. VS Code 터미널에서 아래 명령을 위에서부터 한 줄씩 실행합니다.

cd D:\Projects\baro-cheori
Expand-Archive -LiteralPath ".\baro-cheori-content-v5-20260818.zip" -DestinationPath "." -Force
Remove-Item -LiteralPath ".\baro-cheori-content-v5-20260818.zip"
npm run lint
npm run build

4. build 마지막에 52개 정적 페이지 생성 성공이 보이면 아래 명령을 실행합니다.

git add .
git commit -m "add delivery and internet troubleshooting guides"
git push

5. Netlify는 GitHub main 브랜치의 새 커밋을 자동으로 배포합니다.
   수동 Trigger deploy는 누르지 않아도 됩니다.
   Netlify Deploys 목록 맨 위가 Published가 되면 완료입니다.

6. 배포 후 아래 주소를 차례로 엽니다.

https://baro-cheori.netlify.app/
https://baro-cheori.netlify.app/company/coupang/delivery-not-received
https://baro-cheori.netlify.app/company/kt/internet-trouble
https://baro-cheori.netlify.app/company/lguplus/internet-trouble
https://baro-cheori.netlify.app/sitemap.xml

눈으로 확인할 변화

- 홈 자주 찾는 업무에 쿠팡 `배송 지연·미도착`이 표시됩니다.
- 홈 자주 찾는 업무에 LG U+ `인터넷 연결 안 됨`이 표시됩니다.
- 쇼핑몰 4곳에 배송 지연·미도착 안내가 하나씩 추가됩니다.
- 통신사 3곳에 인터넷 연결 안 됨 안내가 하나씩 추가됩니다.
- 상세페이지에서 공식 진단 버튼과 정확한 고장 전화번호가 먼저 보입니다.
- 사이트맵 URL 수는 기존 39개에서 46개로 늘어납니다.

검색엔진 작업

- Google과 Naver에 sitemap.xml을 다시 제출할 필요는 없습니다.
- 이미 등록된 같은 sitemap.xml 주소를 검색엔진이 다시 읽으면서 새 페이지를 발견합니다.
- 새 페이지 노출은 바로 생기지 않을 수 있으며 며칠 이상 걸릴 수 있습니다.

문제 확인

- Expand-Archive에서 경로 오류가 나면 ZIP이 D:\Projects\baro-cheori 안에 있는지 확인합니다.
- git commit에서 nothing to commit이 나오면 압축이 프로젝트 폴더에 덮어써지지 않은 것입니다.
- build가 52개 정적 페이지를 만들고 종료되면 정상입니다.
- Remove-Item은 압축 해제가 끝난 V5 ZIP만 지우며 코드 파일은 지우지 않습니다.
