바로처리 V8 카드사 업데이트 적용 방법
=====================================

앞으로 업데이트 ZIP은 프로젝트 폴더 안에서 적용합니다.

1. ZIP 파일을 아래 폴더 안으로 옮깁니다.

D:\Projects\baro-cheori

파일명:
baro-cheori-card-v8-20260818.zip

2. VS Code 터미널에서 아래 명령을 한 줄씩 실행합니다.

cd D:\Projects\baro-cheori
Expand-Archive -Path ".\baro-cheori-card-v8-20260818.zip" -DestinationPath "." -Force
Remove-Item ".\baro-cheori-card-v8-20260818.zip"
npm run lint
npm run build
git add .
git commit -m "add card loss and fraud guides"
git push

3. 정상 빌드 확인 문구

Generating static pages ... (89/89)

4. 배포 뒤 화면에서 확인할 변화

- 상단 카테고리: 쇼핑몰 · 통신사 · 택배 · 카드
- 카드 업체: KB국민카드 · 신한카드 · 삼성카드
- 홈 제공량: 현재 13개 업체의 66개 업무
- 홈 인기 업무에 KB국민카드 카드 분실·즉시 정지 표시
