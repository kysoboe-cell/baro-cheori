## 1. [전역 · 최우선] 카드/메뉴 순서를 인기도 기준으로 재배열

**문제**
업체별 상세 페이지(예: 쿠팡)에서 카드 순서가 실제 수요와 무관하게 배치돼 있음. 현재 쿠팡 페이지 순서: `주문취소 → 와우 멤버십 해지·다음 결제 막기 → 반품·환불 → 와우 결제취소·환불확인 → 배송지연·미도착 → 교환 → 반품회수 안됨`.

유석 님 판단: 실제로 제일 많이 찾을 항목은 **와우 멤버십 해지**인데 지금은 2번째, "주문취소"처럼 상대적으로 덜 찾을 법한 항목이 1번을 차지하고 있음.

**요구사항**
- 모든 업체 상세 페이지의 카드 순서를 "실제 검색 수요/인기" 기준으로 재정렬
- 쿠팡 페이지 한정 명확한 지시: **"와우 멤버십 해지·다음 결제 막기"를 1순위(맨 위)로 이동**
- 다른 업체(통신사/카드/구독/전자·가전) 페이지도 같은 원칙 적용. 이미 있는 `콘텐츠_보강_우선순위.md`(구글 트렌드 상대비교 조사, Tier 1/2 데이터)를 우선 참고해서 순서를 정하고, 데이터가 없는 나머지는 "구독 해지류가 전반적으로 상위"라는 상식적 가정으로 우선 배치. 이후 GA4 데이터가 쌓이면(9월 예정 색인 확인과 함께) 실측치로 재조정
- 웹/모바일 동일 순서로 적용 (모바일에서도 같은 순서 문제 확인됨 — 아래 4번과도 연동)

**영향 범위**: 홈 화면의 "다들 이것부터 찾아요" 카드 구성도 같은 원칙으로 한번 점검(이미 수요 중심으로 4개 골라둔 상태이긴 하나, 우선순위 재검토 겸)

## 2. [홈 화면] 검색창 예시(placeholder) 문구 교체

**문제**
현재 검색창 placeholder: `예: 삼성 세탁기 고장, LG 출장수리`. 메인 화면은 방문자가 3~5초 안에 "이 사이트가 나한테 쓸모 있나"를 판단하는 가장 중요한 지면인데, 지금 예시 문구가 사이트의 핵심 가치(구독 해지, 카드 분실 등 다양한 수요)를 대표하지 못함.

**요구사항**
- 사이트에서 다루는 항목 중 실제로 가장 인기 있을 법한 키워드로 교체 (예: "쿠팡 와우 해지", "넷플릭스 해지" 등 — 1번 항목의 인기도 재조사 결과와 맞춰서 최종 문구 확정)
- **모바일 폭을 반드시 함께 고려**: 웹에서 예시 문구를 정할 때 모바일 검색창 폭에서도 줄바꿈되거나 잘리지 않는 길이인지 확인. (모바일 검색창은 웹보다 훨씬 좁음 — 스크린샷 기준 placeholder가 이미 "LG 출장수..."로 잘려 보이는 상태)

## 3. [모바일 홈] 서브헤드라인 줄바꿈이 어색함

**문제**
"처리 순서와 진짜 필요한 연락처까지, 검색 한 번이면 바로 나와요." 문장이 모바일 폭에서 어절 단위가 아니라 어색한 지점에서 줄바꿈됨 (예: "검색 한" 에서 끊기고 다음 줄 "번이면 나와요"로 이어지는 식 — 읽었을 때 부자연스러움).

**요구사항**
- 모바일 뷰포트(390px 기준) 실측해서 자연스러운 어절 단위로 줄바꿈되도록 조정. 필요하면 문장 자체를 줄이거나, 특정 지점에 명시적 줄바꿈(`<br>` 또는 `white-space: pre-line` 등)을 넣어 강제
- 웹 폭에서는 문제 없었으므로 반응형으로 모바일에서만 줄바꿈 지점을 제어하는 방식 권장

## 4. [상세 페이지 · 핵심 구조 개선] "방법 절차 한눈에 보기" 아코디언 신설

**배경**
"화면 그대로 따라하기" 스샷 격자 섹션(3열 썸네일 + 라이트박스)은 완성도가 매우 높다는 평가. 다만 본문 하단(처리 순서 다음)에 위치해서, 우측 사이드바("시작 전 준비" / "주의" / "직접 해결이 막혔을 때")까지 다 본 뒤에도 스크롤을 더 내려야 도달함.

**아이디어 (유석 님 제안)**
우측 사이드바 맨 위 — "시작 전 준비" 카드 **바로 위**에 새 아코디언(접기/펼치기) 카드를 하나 추가:
- 제목: "방법 절차 한눈에 보기" (가제, 카피는 클코 재량으로 다듬어도 됨)
- 접힌 상태가 기본값
- 클릭하면 그 자리에서 기존 "화면 그대로 따라하기" 섹션과 동일한 콘텐츠(스샷 3열 격자 + 라이트박스)가 펼쳐짐
- 목적: 스크롤 없이 페이지 상단만으로 전체 절차를 훑어볼 수 있게 해서 사용자 이탈을 줄이고 "이 사이트는 진짜 편하다"는 인상을 즉시 주는 것

**요구사항**
- 스샷 가이드가 있는 페이지에만 노출 (기존 "화면 그대로 따라하기" 섹션 노출 조건과 동일한 조건 재사용)
- 데스크톱 사이드바 우선 적용. 모바일은 이미 스텝 리스트 직후에 격자가 배치돼 있어 상대적으로 급하지 않음 — 모바일까지 확장할지는 적용 후 판단
- 콘텐츠 중복(같은 이미지 두 번 렌더링)으로 인한 페이지 무게 증가를 피하려면, 아코디언 펼침 시 기존 하단 섹션과 같은 DOM/이미지를 재사용(앵커 이동 또는 컴포넌트 공유)하는 방식도 고려 가능. 다만 사용성이 최우선이므로 완전히 별도로 새로 렌더링해도 무방 — 클코 판단에 맡김

## 5. [모바일] 업체 상세 페이지 카드 목록을 2열×3행 축소 그리드로

**문제**
모바일에서 업체별 업무 카드(주문취소 / 와우 멤버십 해지 / 반품·환불 / 와우 결제취소·환불확인 / 배송 지연·미도착 / 교환 ...)가 세로 스택으로 나열돼 스크롤이 김. 모바일 사용자가 최우선 고객층인데, 스크롤 부담이 큰 상태로 두면 이탈 위험.

**요구사항**
- 모바일 전용 반응형으로, 상위 6개 카드를 **2열 × 3행(총 6개, "2×2×2")** 축소 그리드로 압축 표시
  - 카드는 컴팩트하게: 제목만 또는 제목 + 1줄 요약 정도로 축소 (현재처럼 2줄 설명문 전부 넣지 않음)
- 6개를 초과하는 나머지 항목은 그리드 아래에 기존 방식(세로 카드 또는 리스트)으로 이어서 배치
- **1번 항목(인기순 재배열)과 반드시 연동**: 이 압축 그리드 상단 6칸에 실제 인기 상위 항목이 들어가야 의미가 있음. 순서 작업과 그리드 작업을 같은 배포에 묶어서 진행할 것
- 웹(데스크톱)은 기존 카드 레이아웃 유지 — 이번 압축은 모바일 전용

---

## 우선순위 정리 (클코 작업 순서 제안)

1. 1번(카드 순서 재배열) — 다른 항목의 전제 조건이므로 먼저
2. 5번(모바일 2x3 그리드) — 1번과 같은 배포로 묶기
3. 2번(검색창 예시 문구) — 간단, 홈 1곳만 수정
4. 3번(모바일 줄바꿈) — 간단, 홈 1곳만 수정
5. 4번(사이드바 아코디언 신설) — 구조 변경이라 상대적으로 공수 큼, 별도 검증 필요
