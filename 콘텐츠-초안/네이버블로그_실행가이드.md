## 1. "글만 올려도 충분한가?" → 사진 넣는 게 낫습니다. 그리고 우리는 이미 있습니다

**사진을 넣는 게 좋은 이유는 세 가지입니다.**

1. 사람이 오래 머뭅니다. 글만 있으면 스크롤 몇 번에 끝나는데, 사진이 있으면 하나씩 봅니다. 네이버는 **얼마나 오래 머물렀는지**를 중요하게 봅니다.
2. 우리 글은 "이 버튼을 누르세요"가 핵심입니다. 말로만 하면 "톱니바퀴가 어디야" 소리가 나옵니다.
3. 다른 블로그는 아무 상관 없는 무료 이미지를 갖다 붙입니다. **우리는 실제 앱 화면에 동그라미까지 쳐 놓은 게 있습니다.** 이건 흉내내기 어려운 차별점입니다.

**그래서 준비했습니다: `네이버블로그_이미지_18장.zip`**

- 사이트에 쓰는 그 스크린샷 그대로. 개인정보 가림 처리 끝난 것들입니다
- 네이버 에디터가 확실히 받는 **JPG로 변환**해 뒀습니다 (사이트는 webp인데 네이버에서 문제 생길 수 있어서)
- 압축을 풀면 글별로 폴더가 나뉘고, 파일 이름이 `1_마이쿠팡`, `5_해지하기`처럼 **넣을 순서 그대로**입니다. 순서대로 하나씩 넣으면 됩니다

### 어디에 넣나

초안 본문의 번호 목록 **바로 아래**에 그 번호에 해당하는 사진을 넣으세요.

**1편 (쿠팡)** — "■ 전체 순서"의 1~7번 목록 아래에 7장을 순서대로. 특히 이 두 장은 꼭 넣으세요:
- `5_해지하기.jpg` → "해지하기는 화면 중간에 있습니다" 문단 아래
- `7_해지신청완료하기.jpg` → "마지막 화면이 진짜 함정입니다" 문단 아래

**2편 (넷플릭스)** — "■ 앱에서 하는 전체 순서" 아래에 7장. 특히:
- `5_멤버십해지.jpg` → "5번에서 조심하세요" 아래 (계정 삭제 함정)
- `7_검은해지완료.jpg` → "7번이 진짜 마지막입니다" 아래

**3편 (삼성)** — 4장. 특히:
- `1_출장비기준.jpg` → 출장비 금액 적은 문단 아래
- `4_품목별보증기간.jpg` → 보증기간 표 설명 아래

전부 안 넣어도 됩니다. **각 글에 3~4장만 넣어도 충분합니다.** 위에 "꼭"이라고 표시한 것들 위주로요.

## 2. 캐릭터 이모티콘·스티커 → 안 사셔도 됩니다

라인 이모티콘 같은 거 **돈 주고 사지 마세요.** 이유는 이렇습니다.

- 우리 글은 **답을 찾으러 온 사람**이 읽습니다. "쿠팡 와우 해지" 검색해서 들어온 사람은 귀여운 캐릭터를 보러 온 게 아닙니다. 빨리 해지하고 싶은 겁니다.
- 스티커가 많으면 오히려 **가벼워 보입니다.** 카드 분실이나 수리비처럼 돈이 걸린 얘기에서는 신뢰가 깎입니다.
- 꾸미기로 이기려면 이미 잘하는 블로거들과 붙어야 합니다. 우리가 이길 수 있는 건 꾸밈이 아니라 **정확한 정보**입니다.

정 허전하면 네이버 에디터에 **기본으로 들어 있는 무료 스티커**가 있습니다. 글 맨 끝 인사말 정도에 하나만 쓰세요. 본문 중간에는 넣지 마세요.

대신 이건 하세요 — 네이버 에디터의 **[인용구]와 [구분선]** 기능입니다. 초안의 `■` 표시한 소제목을 인용구로 바꾸면 훨씬 읽기 좋아집니다. 무료고 클릭 두 번입니다.

## 3. 블로그 이름 후보

지금 이름이 촌스럽다고 하셨는데, **블로그 이름은 언제든 바꿀 수 있습니다** (블로그 주소/아이디는 못 바꿉니다 — 그건 그냥 두세요, 상관없습니다).

사이트와 이름을 맞추면 나중에 "바로처리"라는 브랜드 검색이 생겼을 때 블로그도 같이 걸립니다.

**추천 (사이트와 한 몸으로 보이게)**
- `바로처리 노트`
- `바로처리 — 생활문제 처리 순서`
- `복잡한 건 바로처리`

**설명형 (검색어가 이름에 들어감)**
- `해지·환불·분실 처리 노트`
- `생활문제 처리 순서 기록`

저라면 **`바로처리 노트`**를 고르겠습니다. 짧고, 사이트와 이어지고, 블로그다운 이름입니다.

**블로그 소개글도 같이 바꾸세요** (검색 결과에 같이 뜹니다):
```
구독 해지, 카드 분실, 반품, 가전 수리처럼 헷갈리는 생활 문제의 처리 순서를 실제 화면과 함께 정리합니다. 전체 정리는 barocheori.com
```

**바꾸는 곳**: 내 블로그 → 우측 상단 `관리` → `기본 설정` → `블로그 정보`에서 블로그명·소개글 수정 → 확인

## 4. 글 올리는 법 (블로그 처음이신 분용, 순서대로)

1. `blog.naver.com` 접속 → 로그인 → **`내 블로그`**
2. 위쪽 **`글쓰기`** 버튼
3. **제목** 칸에 초안의 제목을 붙여넣기
4. **본문** 칸을 클릭하고 초안 본문을 붙여넣기
   - 붙여넣을 때 **`Ctrl + Shift + V`**를 쓰세요. 그냥 `Ctrl+V`하면 색깔이나 서식이 딸려와서 지저분해집니다
5. **사진 넣기**: 사진을 넣을 위치에 커서를 두고 → 위쪽 도구모음의 **`사진`** 아이콘 → 파일 선택 → 열기
   - 여러 장을 한 번에 고르면 순서대로 들어갑니다
6. **태그**: 본문 아래쪽 `태그 편집`을 누르고 초안의 태그를 하나씩 입력 (`#` 없이 단어만, 엔터로 구분)
7. 오른쪽 위 **`발행`** 클릭 → 발행 창에서:
   - **카테고리**: `생활정보` 같은 걸 하나 만들어 두고 3편 다 같은 데로
   - **공개 설정**: **`전체공개`**
   - **`검색 허용`** 체크되어 있는지 **꼭 확인** ← 이게 꺼져 있으면 네이버 검색에 절대 안 뜹니다. 제일 중요합니다
   - `이 설정을 기본값으로 유지` 체크해 두면 다음부터 안 건드려도 됩니다
8. **`발행`** 누르면 끝

### 올린 뒤에 하면 좋은 것 (선택)

발행하고 나면 글 주소가 생깁니다. 그 주소를 **네이버 서치어드바이저 → 요청 → 웹 페이지 수집**에 넣으면 조금 더 빨리 잡힙니다. (8/19에 유석 님이 사이트 등록하실 때 쓰셨던 그 화면입니다)

## 5. 다시 말씀드리지만 — 급하지 않습니다

구글 색인이 이미 붙었으니 블로그는 **여유 될 때** 하시면 됩니다. 3편을 하루에 몰아 올리지 마시고 **사흘에 걸쳐 하루 한 편씩**만 지켜주세요. 새 블로그가 하루에 여러 글을 쏟아내면 네이버가 좋게 보지 않습니다.

순서는 **1편(쿠팡) → 2편(넷플릭스) → 3편(삼성)** 을 권합니다. 검색량이 큰 순서이고, 1편이 사진이 제일 잘 나와 있습니다.
