# 가전 Tier 1 페이지 콘텐츠 보강 초안 (2026-08-20)

기존 페이지 4개를 실제로 열어서 구조를 확인했고, 이미 "처리 순서(5단계) + 준비물 + 주의사항 + 공식 링크 + 전화번호 + 관련 업무" 템플릿으로 잘 짜여 있음. 완전히 새로 쓰는 게 아니라 **"수리비" 검색 의도를 직접 겨냥하는 섹션 2개를 각 페이지에 추가**하는 방향으로 초안 작성함.

- 추가 섹션 A: **품목별 대략 수리비 참고표** (지금 페이지에 없는, "수리비" 키워드가 직접 원하는 정보)
- 추가 섹션 B: **자주 묻는 질문(FAQ)** 3~4개 (롱테일 키워드 흡수 + 체류시간 증가)

기존 페이지의 "정확한 총액은 점검 후 확정" 톤은 그대로 유지하고, 참고표는 "확정 금액이 아닌 대략적 범위"라는 점을 표 위/아래에 명시함. 가격 수치는 실제 공식 요금표에서 최종 확인 필요 — Claude Code 쪽에서 반영 전에 삼성/LG 공식 요금 페이지 한 번 더 대조 권장.

## 1. `/company/samsung-electronics/repair-cost-warranty` 추가 콘텐츠

### 섹션 A. 품목별 대략 수리비 참고표

> 아래 금액은 부품 종류·모델·지역에 따라 달라지는 **대략적인 참고 범위**입니다. 정확한 금액은 방문 점검 후 견적으로 확정돼요.

| 제품 | 흔한 고장 유형 | 출장비(참고) | 수리비 대략 범위(참고) |
|---|---|---|---|
| 세탁기 | 배수 불량, 기판 고장, 모터 소음 | 약 2~3만원 | 3만원~15만원대 |
| 냉장고 | 냉각 안 됨, 소음, 컴프레서 문제 | 약 2~3만원 | 5만원~20만원대(컴프레서 교체 시 더 높음) |
| TV | 화면 얼룩, 전원 불량, 패널 손상 | 약 2~3만원 | 화면 패널 교체는 신제품 구매와 비교 필요할 정도로 고가일 수 있음 |
| 에어컨 | 냉방 안 됨, 가스 부족, 누수 | 약 2~3만원 | 가스 충전 5만원대~, 부품 교체 시 그 이상 |
| 휴대폰 | 액정 파손, 배터리 불량 | 방문 아님(센터 접수) | 액정 10만원대~, 배터리 3~5만원대(모델별 편차 큼) |

### 섹션 B. 자주 묻는 질문

**Q. 보증기간 안인데 왜 비용이 나올 수 있나요?**
낙하·침수·임의개조 같은 사용자 과실, 소모품 교체(배터리 등)는 보증기간 안이어도 유상 처리되는 경우가 많아요.

**Q. 출장 신청만 해도 무조건 출장비가 나가나요?**
기사가 방문해 점검한 이상 수리를 진행하지 않아도 출장비가 청구되는 경우가 일반적이에요. 방문 전 전화 상담으로 대략적인 원인을 먼저 좁혀보는 것도 방법이에요.

**Q. 수리비가 너무 비싸면 어떻게 하나요?**
견적을 들은 뒤 수리 여부는 그 자리에서 거절할 수 있어요. 다만 이미 진행된 점검에 대한 출장비는 발생할 수 있으니, 고가로 예상되는 고장(패널, 컴프레서 등)은 방문 전 대략적인 비용대를 미리 물어보는 게 좋아요.

## 2. `/company/lg-electronics/repair-cost-warranty` 추가 콘텐츠

| TV(OLED 포함) | 화면 불량, 전원 문제 | 약 2~3만원 | 패널 손상 시 고가, 신제품 구매와 비교 권장 |
| 에어컨(휘센 등) | 냉방 안 됨, 가스 부족 | 약 2~3만원 | 가스 충전 5만원대~ |
| 스타일러 | 냄새 제거 안 됨, 문 고장 | 약 2~3만원 | 부품별 상이, 점검 후 확정 |

### 섹션 B. 자주 묻는 질문

**Q. 일반제품·계절제품·휴대전화 보증기간이 왜 다른가요?**
LG전자는 제품군별로 무상보증 기준이 달라요. 예약 전에 [요금/보증] 페이지에서 내 제품군의 기준을 확인하는 게 정확해요.

**Q. 점검만 받아도 비용이 나오나요?**
고장이 아닌 단순 점검 요청도 기사 방문이 이뤄지면 비용이 발생할 수 있어요.

**Q. 수리 대신 새 제품을 사는 게 나을 때는 언제인가요?**
수리비가 신제품 가격의 절반을 넘어가는 경우(특히 패널·컴프레서 교체) 새 제품 구매와 비교해보는 걸 권장해요.

## 3. `/company/samsung-electronics/service-center` 추가 콘텐츠

### 섹션 B. 자주 묻는 질문 (이 페이지는 가격표보다 FAQ가 더 적합)

**Q. 예약 없이 그냥 방문해도 되나요?**
가능하지만 대기 시간이 길어질 수 있어요. 특히 휴대폰은 대기현황을 먼저 확인하고 가는 걸 추천해요.

**Q. 가까운 센터인데 왜 수리가 안 된다고 하나요?**
센터마다 취급하는 제품군이 달라요(대형가전 전문/휴대폰 전문 등). 방문 전 [수리 가능 제품]에서 반드시 확인하세요.

**Q. 주말에도 방문할 수 있나요?**
일부 센터는 주말 운영을 하지만 전체는 아니에요. 예약 화면에서 센터별 운영시간을 확인하세요.

## 4. `/company/lg-electronics/service-center` 추가 콘텐츠

### 섹션 B. 자주 묻는 질문

**Q. LG전자서비스센터도 온라인 예약이 되나요?**
가능해요. LG전자 공식 페이지에서 지역과 제품을 선택해 예약할 수 있어요.

**Q. 방문 전 미리 확인할 게 있나요?**
제품 모델명, 구입일자(영수증), 고장 증상을 사진으로 준비해가면 접수와 점검이 빨라져요.

**Q. 대형가전도 센터로 가져가야 하나요?**
세탁기·냉장고 같은 대형가전은 대부분 방문(출장) 수리로 진행돼요. 센터 방문은 소형가전·휴대용 제품 위주예요.
