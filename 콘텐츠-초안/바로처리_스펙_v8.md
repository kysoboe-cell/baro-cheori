## 1. 새로 발견된 문제 — 모바일에서 후원 버튼이 아예 없습니다

유석 님이 "모바일에서 잘 안 보인다"고 하셨는데, 실제로는 **안 보이는 게 아니라 존재하지 않습니다.**

`app/components/CoffeeSupport.tsx` 최상단:

```tsx
<div ref={rootRef} className="relative hidden sm:block">
```

`hidden sm:block` → **640px 미만에서는 렌더 자체가 안 됩니다.** 그리고 `SiteFooter.tsx`에 후원·계좌·커피 관련 문구가 **0건**입니다.

즉 **모바일 방문자에게는 후원 경로가 하나도 없습니다.** 이 사이트는 "사람들은 문제 생기면 폰으로 해결한다"를 전제로 모바일 우선으로 만들었으니, 사실상 대부분의 방문자에게 후원 창구가 닫혀 있는 셈입니다.

원인은 스펙 v3 4-7의 "플로팅 커피 버튼은 모바일 제거·데스크톱 헤더 pill"입니다. 의도는 **본문을 가리는 플로팅 버튼**을 없애는 것이었는데, 구현이 대체 경로 없이 통째로 숨기는 쪽으로 갔습니다.

### 고치는 방향 — 플로팅은 되살리지 않습니다

상세 페이지 하단에는 이미 `FixedBottomCTA`(전화 걸기 / 공식 페이지)가 고정돼 있어서 플로팅 버튼을 되살리면 겹칩니다. 대신 **가리지 않는 자리 두 곳**에 둡니다.

**① 푸터 후원 블록 (모바일·데스크톱 공통, 기본 경로)**

`SiteFooter.tsx`에 후원 블록을 추가합니다. 항상 있고, 본문을 가리지 않고, 스크롤 끝까지 읽은 사람만 봅니다.

- 제목: `☕ 도움이 되셨다면 개발자에게 커피 한잔을`
- 설명 한 줄: `바로처리는 광고 없이 무료로 운영됩니다. 후원 여부는 서비스 이용에 아무 영향이 없어요.`
- `우리은행 · 예금주 김X석` / 계좌번호 `1002-053-103-089` (`tnum` 적용)
- `계좌번호 복사` 버튼 (최소 높이 48px) — 복사 로직은 `CoffeeSupport.tsx`의 것을 그대로 재사용하세요. **복사 코드를 두 벌로 만들지 마세요.**
- 다크 배경이므로 글자는 기존 푸터 색 체계(`text-gray-300`)를 따르고, 계좌번호만 흰색으로 대비를 줍니다

**② "도움됐어요" 직후 한 줄 (모바일 포함, 고의도 순간)**

`PageFeedback.tsx`에서 **`도움됐어요`를 누른 경우에만** 지금의 "의견 감사합니다." 자리에 한 줄을 더합니다.

```
의견 감사합니다. ☕ 커피 한잔 후원하기
```

- `아쉬워요`를 누른 경우에는 **띄우지 마세요.** 도움이 안 됐다는 사람에게 후원을 권하는 건 무례합니다.
- 링크는 푸터 후원 블록으로 점프(`#support`)하거나, 그 자리에서 계좌 한 줄이 펼쳐지게 하거나 둘 중 편한 쪽으로. 새 창은 열지 마세요.
- 레이아웃이 밀리지 않게 지금의 `min-h-12`는 유지하세요.

**③ 데스크톱 헤더 pill은 지금 그대로 둡니다.**

### 하지 말 것
- 모바일 플로팅(떠다니는) 버튼 되살리기 — v3에서 없앤 이유가 그대로 유효합니다
- 상세 페이지 본문 중간에 후원 넣기 — 처리 순서를 끊습니다
- 하단 고정 CTA 옆에 붙이기 — 전화 버튼 오클릭을 유발합니다

## 2. 잔손질 A — 업체 카드 요약이 데이터 원문 그대로 나옵니다

클코가 "미조치 1"로 남긴 항목입니다. 고치는 게 맞습니다.

`/company/coupang` 카드 설명에 이렇게 나옵니다:

```
마이쿠팡 → 설정(톱니바퀴) → [와우 멤버십] → 중간까지 스크롤 → [해지하기] 순서예요.
```

상세 페이지에서는 같은 문장이 `StepText`를 거쳐 `→`는 `>`로, `[대괄호]`는 굵은 글씨로 렌더됩니다. 업체 페이지만 날것입니다. 같은 문장이 페이지마다 다르게 보이는 건 v7에서 맞춘 "같은 사이트로 보인다"와 어긋납니다.

**작업**: `ServiceCard.tsx`의 `summary`를 그냥 `{summary}`로 찍지 말고 `<StepText text={summary} />`로 감싸세요. 문구 자체는 건드리지 않습니다 — 렌더 방식만 상세 페이지와 통일합니다.

`line-clamp`가 걸려 있으니 굵은 글씨가 들어가도 줄 수는 그대로인지만 확인하세요.
