# 바로처리 메인페이지 개선 스펙 (2026-08-20)

직접 사이트 열어서 버그 재현하고 확인한 내용 기준으로 작성. 모바일 UX 개선은 이번 범위에서 제외(다음에 별도 진행).

---

## 1. [버그 수정] 업체 드롭다운이 재클릭해도 안 닫힘 — 최우선

### 재현 방법
1. 상단 "업체로 바로 찾기" 옆 카테고리 버튼(쇼핑몰/통신사/택배/카드/구독/전자·가전) 아무거나 클릭 → 드롭다운 펼쳐짐
2. **같은 버튼을 다시 클릭** → 안 닫힘, 계속 펼쳐진 채로 유지됨
3. 드롭다운이 절대위치(absolute)로 떠 있어서 히어로 타이틀("카드 분실·배송 안 옴·가전 고장, 지금 할 일만 바로")을 덮어버림
4. 유일한 탈출구는 드롭다운 우측 상단의 작은 "닫기" 텍스트 링크 — 근데 이게 너무 작고 눈에 안 띄어서 사용자가 못 찾고 새로고침(F5)으로 대응하게 됨

### 원하는 동작
- 같은 카테고리 버튼을 다시 클릭하면 드롭다운이 **닫혀야 함** (열림/닫힘 토글)
- 다른 카테고리 버튼을 클릭하면 기존 것 닫고 새 걸 여는 것도 유지
- 드롭다운 바깥 영역(배경) 클릭 시에도 자동으로 닫히게
- ESC 키로도 닫히면 좋음 (선택)
- "닫기" 링크는 유지하되, 위 토글이 되면 사실상 있으나 마나 한 안전장치 정도로 남겨도 됨
- **레이아웃 문제도 같이**: 드롭다운이 열렸을 때 히어로 텍스트를 완전히 가리는 대신, 콘텐츠를 살짝 밀어내거나(레이아웃 시프트) 최소한 배경 dim 처리를 해서 "지금 뭔가 열려있다"는 게 명확하게 보이도록. 지금은 그냥 흰 박스가 텍스트 위에 얹혀서 마치 화면이 깨진 것처럼 보임.

## 2. [가독성/구조] 전체적으로 산만한 느낌 개선

지금 구조 자체는 나쁘지 않음(홈 → 카테고리/검색 → 상황별 카드 → 업체별 안내). 문제는 "한 화면에 정보 밀도가 높고 시각적 위계가 약하다"는 점. 구체적으로:

- **색상 절제**: 파란색이 헤드라인 강조, 버튼, 링크, 아이콘 배경 등 여러 군데 동시에 쓰이고 있어서 "지금 뭐가 제일 중요한지" 구분이 잘 안 됨. 파란색은 핵심 액션(검색 버튼, 가장 중요한 CTA) 위주로 좁혀 쓰고, 나머지는 톤 다운된 색(회색 계열)으로 정리 제안
- **히어로 영역 단순화**: 지금 배지("전화 돌리기 전에...") + 헤드라인 3줄 + 서브카피 2줄 + 검색창 + 통계 텍스트(23개 업체·109개 실제 업무 등)까지 세로로 쌓여있어 첫 화면이 빽빽함. 배지는 없애거나 헤드라인에 흡수, 통계는 더 작고 눈에 덜 띄는 톤으로
- **"바로 시작하기" 카드 4개(카드 잃어버림/모르는 결제/배송 안 옴/휴대폰 분실)**: 좋은 요소인데 히어로 옆에 나란히 붙어있어서 시선이 분산됨. 헤드라인이 먼저 읽히고 그다음 이 카드로 자연스럽게 이어지는 세로 배치도 고려해볼만 함
- **"상황별 빠른 해결" 카드들**: 스타일은 일관되게 잘 되어 있음(칭찬할 부분) — 이 스타일을 기준점 삼아 위쪽 히어로 영역도 톤을 맞추면 전체적으로 통일감 생길 것

이 부분은 실제 코드/컴포넌트 구조를 봐야 구체적 수정 범위가 나올 것 같아서, Claude Code가 먼저 관련 컴포넌트(`app/page.tsx` 등) 확인 후 구체적인 수정안을 스크린샷으로 먼저 보여주고 진행하는 걸 추천.

## 3. [카피] 메인 헤드라인 교체

### 기존
> 카드 분실·배송 안 옴·가전 고장, 지금 할 일만 바로

### 유석 님 제안 방향
> 복잡한 ARS 싫으셨죠? 저희 사이트를 통해 간편 매뉴얼을 보고 바로 해결하십쇼. 완전 무료입니다.

### 다듬은 후보안 (택 1, 또는 조합)

**A안 (추천) — 공감 먼저, 짧고 담백하게**
- 헤드라인: **"그 ARS, 이제 안 타셔도 돼요"**
- 서브: "카드 분실, 배송 안 옴, 가전 고장까지 — 검색 한 번이면 처리 순서와 진짜 필요한 연락처만 나와요. 완전 무료."

**B안 — 직접적 문제 제시형**
- 헤드라인: **"고객센터 헤매지 마세요, 바로 해결하세요"**
- 서브: "복잡한 ARS 안 타도 돼요. 문제를 검색하면 지금 뭘 눌러야 하는지 바로 알려드려요."

**C안 — 유석 님 원안에 가장 가깝게, 자연스러운 어투로만 다듬음**
- 헤드라인: **"복잡한 ARS는 이제 그만"**
- 서브: "간편한 처리 순서를 보고 바로 해결하세요. 완전 무료입니다."

**기존 서브카피는 계속 살려도 좋음** ("긴 고객센터 설명을 뒤지지 마세요...") — A/B/C안 중 하나를 헤드라인으로, 기존 서브카피는 그 아래 보조 설명으로 이어 붙이는 것도 방법.

개인적으로는 A안 추천 — "그 ARS"처럼 지시대명사를 써서 사용자가 이미 겪어본 짜증을 콕 짚어주는 게 공감을 더 자연스럽게 만들고, "완전 무료"를 마지막에 짧게 못박아서 신뢰까지 챙김.

## Claude Code 전달 시 참고
- 1번(드롭다운 버그)이 가장 우선순위 높음 — 사용자가 실제로 콘텐츠를 못 읽는 심각한 버그
- 2번(가독성 개선)은 범위가 넓으니, 관련 컴포넌트 먼저 파악하고 구체적 수정안을 스크린샷으로 먼저 보여준 뒤 진행 권장
- 3번(카피)은 A/B/C 중 하나 골라서 반영하거나, 유석 님한테 재확인 받고 진행
