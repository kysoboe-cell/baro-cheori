사이트 심사를 요청하려면 아래 코드가 실사이트 `<head>`에 실제로 올라가 있어야 한다. 배포가 확인되면 애드센스 화면에서 [Verify] → [Request review]를 눌러 심사를 시작한다 (그건 기획실장/유석 님 몫 — 클코는 배포까지만).

## 작업

### 1. `app/layout.tsx` — head의 AdSense 삽입 지점 주석 자리에 아래 코드 추가

```tsx
{/* Google AdSense — 사이트 소유 확인 + 승인 후 광고 로드 (v11) */}
<script
  async
  src="https://pagead2.googlesyndication.com/pagead/js/adsbygoogle.js?client=ca-pub-6669238622556321"
  crossOrigin="anonymous"
/>
```

- JSX라서 `crossorigin`이 아니라 **`crossOrigin`**(대문자 O)로 써야 한다.
- 이 스크립트는 심사 전에는 광고를 그리지 않는다. 화면 변화 0이어야 정상.
- AdSlot 컴포넌트/`NEXT_PUBLIC_ADS` 플래그는 **건드리지 않는다** (여전히 잠든 상태 유지 — 승인 후에 켠다).

### 2. `public/ads.txt` 새 파일 (한 줄)

```
google.com, pub-6669238622556321, DIRECT, f08c47fec0942fa0
```

- 애드센스 표준 ads.txt 형식. 소유 확인 수단이 이중으로 생겨 안전하다.

### 3. 검증·배포

- `npm run build` 통과 확인
- 배포 전 로컬에서: 페이지 소스에 `ca-pub-6669238622556321`이 있는지, **화면에 빈 박스·레이아웃 변화가 없는지** 확인
- `npm run deploy` → 실사이트에서 `view-source`로 head에 스크립트 존재 + `https://barocheori.com/ads.txt` 200 확인 (배포 직후 404는 1~2분 전파 지연이니 재확인)
- 커밋 → push → CLAUDE.md "0. 최신 상태 요약"에 "애드센스 코드 삽입·심사 대기" 한 줄 갱신
